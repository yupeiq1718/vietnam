# hanoi-sights

資料來自 2026-10 規劃河內行程時查的素材（`raw/hanoi-trip-2026-10/`）。每頁的表格都附回溯路徑。行程頁有寫、但 raw 沒有存的資料，放在各頁的「未確認」段落，並標明「raw 沒有存」。
